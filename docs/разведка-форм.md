# Разведка форм отклика

Прогон 2026-09-24: `cd jupiter && python3 recon.py --markdown ../docs/разведка-форм.md`.
Разведчик — Jupiter в dry-run с синтетическим кандидатом: движок с
`read_only=True` пропускает только GET и HEAD, заявки не уходят.
Запросы идут из облачного контейнера, поэтому `blocked` может означать
блок облачного IP или заголовка `User-Agent` Jupiter, а не закрытый сайт.

## Сводка

| Класс | Разделов | Что значит |
|---|---:|---|
| `dry_run_ok` | 25 | dry-run пройден: форма заполнена целиком, отправка остановлена движком |
| `form_unmapped` | 16 | серверная форма есть, но обязательные поля не заполнились — нужна карта |
| `captcha` | 22 | форма за CAPTCHA — только с передачей человеку |
| `aggregator` | 1 | отклик уходит на агрегатор (hh.ru, SuperJob и т. п.) |
| `spa` | 36 | страница рисуется скриптом, серверной формы нет |
| `no_vacancy` | 25 | вакансию или анкету найти не удалось |
| `blocked` | 45 | сайт не отдал страницу (код ответа, DNS, TLS) |
| **всего** | **170** | |

### Почему `blocked`

| Причина | Разделов |
|---|---:|
| доступ (403) | 15 |
| tls | 11 |
| доступ (401) | 6 |
| доступ (reset) | 4 |
| сеть | 3 |
| не HTML | 3 |
| доступ (417) | 1 |
| доступ (451) | 1 |
| 404 | 1 |
