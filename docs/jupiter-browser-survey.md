# Браузерный агент Юпитера на живых сайтах — прогон 29.09.2026

Только dry-run (`read_only=True`): ни одной отправки, движок оборвал 388 не-GET
запросов. 60 сайтов из разовой браузерной пробы: все 26 `form_no_captcha`, все 7
`form_invisible_captcha` и 27 `no_form`. Движок примерно на `2c7f4d7`. Кандидат
синтетический (как `recon.TEST_CANDIDATE`).

## Итог

Настоящую анкету агент заполнил на **18 из 60** сайтов — на 18 из 33, где проба
видела форму (55%). На 27 сайтах без формы по пробе настоящих анкет ноль. Ещё 4
`ready_to_submit` ложные (подписка, пустая форма Tilda), 1 — чужая вакансия.

| Класс по пробе | Сайтов | `ready_to_submit` | Настоящая анкета |
|---|---|---|---|
| form_no_captcha | 26 | 16 | 13 (+1 чужая вакансия, 2 ложных) |
| form_invisible_captcha | 7 | 5 | 5 (капча — человеку) |
| no_form | 27 | 2 | 0 (обе — подписка) |

В среднем 4,3 поля на анкету: имя, фамилия, телефон, почта, резюме, согласие.

## Что чинить в движке (по убыванию пользы)

1. **Анкета за кнопкой, кнопку не нажали — 28× `VACANCY_NOT_FOUND`** (job.rt.ru,
   rabota.metro-cc.ru, gum.ru). `_has_candidate_form` засчитывает поля поиска и
   фильтров. Считать анкетой только формы с именем/телефоном/почтой/файлом.
2. **`read_only` обрывает POST, без которых страница не рисуется** (tensor.ru
   JSON-RPC, orionsoft, a101 jwt, aeroexpress, rush-agency admin-ajax, baltika
   Cloudflare). Смягчение инварианта — **решение владельца**.
3. **Ложный `ready_to_submit` — 4** (job.ginza.ru — 0 полей, Tilda; re-store.ru,
   job.mts.ru, azimuthotels — подписка). Не выдавать при 0 полях, отсеивать
   «почта + согласие», склеивать формы Tilda.
4. **Чужая вакансия** (mish.design, infotecs). Не уходить с карточки вакансии на
   соседнюю — только на ссылку отклика этой же.
5. **Хождение по спискам — 2× `MAX_STEPS`** (reso.ru, career.sibur.ru).
6. **Снимок падает**: gorzdrav.org (`cloneNode` на null), fsk.ru («Execution
   context was destroyed») — проверка на null и повтор снимка.
7. **Блокировка/ошибка страницы как «вакансия не найдена»** (magnit —
   `chrome-error`, pochta.ru — 417 «VPN»): нужен `NAVIGATION_FAILED`/код блокировки.
8. **`MISSING_PROFILE_FIELD` на решаемых полях** (fdoctor «Сообщение» —
   сопроводительное письмо; skyeng «Ссылка на резюме» — `resume_url` в профиле).
9. **`VALIDATION_FAILED` на чужих полях** (fsk.ru: калькулятор ипотеки попал в
   виртуальную форму) — брать поля рядом с кнопкой отправки, а не всю страницу.
10. **Время**: общий бюджет на сайт внутри движка (metro, reksoft > 90 с).

Мелочь: при браузерном движке траектория пишет `"engine": "jupiter-web-engine"`.

## Песочница

`ignore_https_errors=True` в облачной песочнице ломает Chromium
(`ERR_TOO_MANY_RETRIES`). Работает доверие к CA прокси через
`--ignore-certificate-errors-spki-list` и явный `proxy=HTTPS_PROXY`. На сервере
не нужно: там проверка сертификатов обычная.
