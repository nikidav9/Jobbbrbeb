# Внешняя проверка доступности

Точка проверки: `https://jobtoo.ru/health`.

Она проходит через nginx и PHP к локальному PostgREST. Ответ:

- `200 {"ok":true}` — весь путь отвечает;
- `503 {"ok":false}` — PHP не дошёл до PostgREST или база недоступна;
- тайм-аут/ошибка соединения — недоступен сервер или внешний маршрут.

Настройки внешнего пингера:

- метод: `GET`;
- интервал: 60 секунд;
- тайм-аут: 10 секунд;
- условие успеха: HTTP 200 и тело содержит `"ok":true`;
- тревога: после двух последовательных отказов;
- сообщение о восстановлении: после первого успешного запроса.

Локальный `jt-site-watchdog` и GitHub-проверку не отключать, пока внешний
пингер не накопит минимум сутки непрерывной истории.
