# Пилот JobToo × Яндекс Смены

Рабочий план технического подключения. Это не договор и не обещание SLA.
Целевая продуктовая схема — встроенный отклик из JobToo, **если реальный API
Яндекс Смены это поддерживает**. До подтверждения такого API и необходимых
юридических оснований используем безопасный redirect-контур без передачи
персональных данных соискателя.

Пока владелец JobToo не зарегистрировал ИП или ООО, допустим только
ограниченный некоммерческий технический пилот без платежей и передачи
персональных данных соискателей.

## Этап 0 — безопасный redirect-пилот

1. Яндекс предоставляет полный HTTPS JSON-фид и заголовок доступа.
2. JobToo сам забирает все страницы по расписанию.
3. JobToo нормализует поля, скрывает запрещённые формулировки и удаляет дубли.
4. Карточка явно маркируется «Яндекс Смены».
5. Кнопка открывает конечную страницу Яндекса; анкета пользователя из JobToo
   не передаётся.
6. Яндекс при возможности подтверждает согласованную конверсию через
   `POST /api/v1/conversions`.

Персональные данные, интегрированный отклик, бронирование смены и статусы
конкретного человека в этот этап не входят. Этот этап нужен, чтобы проверить
качество и эксплуатацию фида независимо от будущего API отклика.

## Этап 1 — целевой embedded-отклик

Переход возможен только после того, как партнёр подтвердил, что внешний сервис
может создавать отклик и получать его дальнейший статус/итог смены.

До переключения источника из `redirect` в `embedded` нужны одновременно:

- реальный обезличенный пакет HTTP-примеров по
  [`partner-api-intake.md`](./partner-api-intake.md);
- contract-тесты по фактическому API партнёра, а не по придуманной схеме;
- согласованное сопоставление статусов и терминальных исходов;
- подтверждённая idempotency/retry-семантика отклика и callback;
- настроенный sandbox и успешный end-to-end сценарий;
- юридическое основание для передачи необходимых данных соискателя и
  соответствующий consent-flow.

Наш уже построенный embedded-контур описан в
[`partner-application-api.md`](./partner-application-api.md). Если API партнёра
не принимает внешний отклик, этап 1 не имитируется: источник остаётся
`redirect`, а пользователь продолжает откликаться на стороне Яндекса.

## Что передать друг другу

От Яндекса для этапа 0:

- production и test URL фида;
- способ авторизации и контакт технического ответственного;
- ожидаемый объём записей и страниц;
- максимальная задержка изменения/закрытия смены;
- перечень профессий, география, часовой пояс;
- схема deep-link и допустимые UTM-метки;
- определение конверсии и стабильный `event_id` для повторной доставки;
- два тестовых набора: корректный и намеренно ошибочный.

Для этапа 1 дополнительно нужен реальный пакет по
[`partner-api-intake.md`](./partner-api-intake.md): отклик, фактические
статусы/callback, auth, ошибки, rate limits и sandbox-ограничения.

От JobToo:

- [формат входящего фида](./feed-format.md);
- пример: `https://jobtoo.ru/api/v1/sample-feed.json`;
- OpenAPI: `https://jobtoo.ru/api/v1/openapi.json`;
- [контракт уже построенного embedded-контура](./partner-application-api.md);
- название и правила маркировки источника;
- перечень метрик пилота и способ сверки;
- окно технических работ и контакт для эскалации.

## Приёмочные ворота этапа 0

Источник нельзя включать на всю аудиторию, пока не выполнены все условия:

- [ ] 3 последовательных успешных полных обхода;
- [ ] ни одного цикла или обрыва пагинации;
- [ ] 100% записей имеют уникальные `id`, непустой `title` и конечный HTTPS `url`;
- [ ] доля отклонённых записей согласована и объяснена;
- [ ] не менее 95% смен с адресом корректно попадают в метро или координаты;
- [ ] время, дата и оплата проверены минимум на 30 случайных карточках;
- [ ] исчезнувшая или `active:false` смена скрывается после следующего полного обхода;
- [ ] повторная загрузка не создаёт дублей;
- [ ] кнопка ведёт на правильную смену и сохраняет источник;
- [ ] показы, переходы и тестовая конверсия видны по источнику;
- [ ] при ошибке фида старые карточки не удаляются;
- [ ] отключение источника мгновенно исключает его из следующих обновлений;
- [ ] ответственные с обеих сторон провели контрольный созвон по результатам.

## Безопасный запуск

| Этап | Объём | Минимальное наблюдение | Условие перехода |
|---|---:|---:|---|
| Тест | до 100 смен | 24 часа | 3 успешных обхода |
| Ограниченный redirect-пилот | до 1 000 смен | 3 дня | нет критических ошибок, качество полей принято |
| Расширенный redirect-пилот | до 10 000 смен | 14 дней | сверены показы, переходы и конверсии |
| Embedded sandbox | тестовые данные | до прохождения contract/E2E | реальный API отклика и статусов подтверждён |
| Production | согласованный объём | постоянно | договор, юридическая проверка, утверждённые роли сторон и пройденные contract-тесты |

Откат на любом этапе: выключить источник в панели. Уже загруженные строки
остаются для аудита, но новые обходы прекращаются; при необходимости активные
карточки источника гасятся отдельной административной операцией.

## Метрики ежедневного контроля

- активные карточки и изменение к предыдущему дню;
- время последнего успешного полного обхода;
- последовательные ошибки и длительность обхода;
- страницы, полученные, пропущенные и погашенные записи;
- доля карточек без нормализованного метро и профессии;
- показы, переходы, CTR, подтверждённые конверсии;
- конверсия из перехода и расхождение со статистикой партнёра;
- жалобы на неактуальную смену или неверные условия.

Для embedded-этапа к ним добавляются доставка outbox/callback, retries,
расхождение статусов и доля заявок без терминального исхода.

## Правило остановки

Показ новых карточек источника приостанавливается, если нарушена пагинация,
ключ доступа отозван, фид содержит систематически неверные условия либо
невозможно определить, полный ли обход завершён. При временной сетевой ошибке
ранее успешно загруженные карточки не гасятся автоматически: сначала
фиксируется инцидент и связываются технические ответственные.

Embedded-режим отдельно откатывается в `redirect`, если внешний API отклика
или статусов перестал удовлетворять согласованному контракту. Это сохраняет
доступ к вакансиям, не создавая ложного ощущения, что отклик принят JobToo.
