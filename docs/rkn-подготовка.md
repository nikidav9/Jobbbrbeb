## 2. Трансграничная передача — что ещё уходит за пределы РФ

После переезда на московский сервер **хранение — в РФ**. За границу уходит только:

| Сервис | Что уходит | Страна | Статус |
|---|---|---|---|
| **Expo Push** (`exp.host`) | Expo push-токен + технические данные доставки; имя и текст переписки не отправляются в push | США | Основной нативный push-шлюз |
| **Apple APNs** | Платформенная доставка iOS push | США | Используется через push-цепочку iOS |
| **Google FCM** (`google-services.json`, `jobtoo-266b7`) | Платформенная доставка Android push | США | Используется через push-цепочку Android |
| **Telegram** (бот) | telegram_id/chat ID + текст уведомления; текст может содержать сведения из JobToo | Вне РФ | Только при добровольной привязке аккаунта |
| ~~Supabase (облако)~~ | — | — | ✅ Больше не используется (данные в РФ) |
| **Yandex Metrika** | Обезличенная веб-аналитика | РФ | ОК, нужен баннер |

Для push-каналов имя пользователя и текст переписки **намеренно не передаются**:
наружу уходит минимизированное служебное уведомление и технические данные
доставки. Telegram — отдельный добровольный канал: туда передаётся chat ID и
текст уведомления, поэтому его нужно описывать в уведомлении о трансграничной
передаче отдельно от push.

- **Минимизация в заграничных каналах** (пуши без имени/текста).
- **Геокодер — Яндекс (РФ)** как основной, Nominatim только запасной.
- **Прокси на сервисном ключе**, секреты не в бандле; канал HTTPS.
