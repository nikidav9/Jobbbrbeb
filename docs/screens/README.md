# Снимки экранов: УСТАРЕЛИ

Эти изображения показывают прежнее устройство приложения. У работника на них
вкладки «Поиск · Мэтчи · Биржа · Чаты · Профиль»; в нынешнем приложении —
«Подработка · Работа · Мэтчи · Общение · Профиль», а вкладки «Биржа» нет вовсе
(см. `app/(tabs)/_layout.tsx`).

**Не описывать по ним интерфейс и не отдавать их наружу.** Однажды по ним были
написаны тексты для магазинов приложений — с разделом, которого в продукте уже
не существовало.

Годятся как история. Для чего угодно ещё — снимать заново.
