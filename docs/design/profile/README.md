# JT — редизайн раздела «Профиль»

Мобильное приложение JT (Job Tools) для поиска работы: соискатель свайпает вакансии и откликается на них.
В архиве — макеты нового раздела «Профиль» в новом дизайне приложения и описание дизайн-системы.

## Что в архиве

- `screens/` — 4 экрана профиля, самостоятельные HTML-файлы (открываются в браузере, ширина 390 px). Вкладки кликаются.
  - `1-profile-resume.html` — вкладка «Резюме»
  - `2-profile-personal.html` — вкладка «Личные»
  - `3-profile-files.html` — вкладка «Файлы» (сейф резюме)
  - `4-profile-reviews.html` — вкладка «Отзывы» (пустое состояние)
- `references/new-design-*.png` — утверждённые экраны нового дизайна (онбординг, вход, регистрация, лента, вакансия, отклики). Это эталон стиля.
- `references/old-profile-video-frames.jpg` — кадры текущего (старого) профиля: какие данные и функции в нём есть. Функциональность сохранить, стиль — заменить.

## Дизайн-система

### Цвета
| Токен | HEX | Где |
|---|---|---|
| `bg` | `#F4EEE5` | Фон экрана (тёплый кремовый) |
| `surface` | `#FFFFFF` | Карточки |
| `ink` | `#151413` | Текст, обводки, тени, нижнее меню |
| `accent` | `#FF6A1F` | Главные кнопки, активные табы/чипсы, маркеры |
| `peach` | `#FFE2CC` | Подложки иконок, иллюстраций, плашка зарплаты |
| `muted` | `#756E66` | Вторичный текст, подписи |
| `line` | `#EFE8DD` | Разделители, пустые сегменты шкал |
| `chip-border` | `#E2D8CA` | Неактивные светлые чипсы |

Текст на оранжевом — всегда чёрный (`ink`), не белый. Ссылки — чёрный текст с оранжевым подчёркиванием 2 px.

### Типографика
- Заголовки: **Unbounded** 700–800 (широкий жирный гротеск), letter-spacing слегка отрицательный. H1 экрана 28 px, заголовок карточки 16–21 px.
- Текст: **Onest** 400–700. Основной 14–15 px, подписи 12–13 px.
- Надписи секций: 11 px, 700, ЗАГЛАВНЫМИ, letter-spacing 0.08em, цвет `muted` (например «ЕЩЁ О СЕБЕ»).
- Шрифты подобраны по виду; если в приложении свои — заменить.

### Фирменные приёмы
- **Жёсткая тень без размытия**: `box-shadow: 4px 4px 0 #151413` + обводка `1.5px solid #151413`. Для акцентных карточек, главных кнопок, плашки зарплаты.
- **Инвертированная карточка-призыв**: фон `ink`, тень оранжевая `4px 4px 0 #FF6A1F`, оранжевая квадратная иконка слева.
- Обычные карточки: белые, `border-radius: 20px`, без обводки и тени, padding 18 px.
- Кнопки и чипсы — пилюли `border-radius: 999px`, обводка 1.5 px `ink`.
- Главная кнопка: оранжевая, обводка + тень `3px 4px 0 ink`, высота 54 px.
- Круглые кнопки-иконки 34–40 px с обводкой (редактировать, помощь, уведомления, настройки).
- Кнопка «+»: оранжевый круг 32 px, обводка и тень `2px 2px 0 ink`.
- Буллеты — маленькие оранжевые квадраты 6×6.
- Иконки — линейные (stroke 1.9, скруглённые концы), 15–20 px. Без эмодзи.
- Иллюстрации: персиковый круг-подложка, объекты с толстой чёрной обводкой, оранжевые акценты, звёздочки-искры.
- Нижнее меню: плавающая чёрная пилюля, активный пункт — оранжевая пилюля с чёрным текстом (Вакансии / Отклики / Профиль).

## Структура экранов профиля

Общее для всех вкладок: верхняя строка (логотип JT, кнопки Помощь / Уведомления / Настройки), заголовок «Профиль», карточка пользователя (аватар с кнопкой камеры, имя, бейдж «Работник», email, рейтинг звёздами → ведёт на «Отзывы»), табы-пилюли Резюме / Личные / Файлы (со счётчиком) / Отзывы, нижнее меню.

1. **Резюме**: призыв «Обновить резюме» (PDF до 10 МБ, поля заполнятся сами) → желаемая должность + зарплата + плитки (опыт, занятость, формат, город) → опыт работы (места работы, буллеты, «Показать полностью», «Добавить место работы») → языки со шкалой уровня из 6 сегментов → навыки чипсами (+N ещё) → одна карточка «Ещё можно добавить» со всеми пустыми разделами (образование, экзамены, сертификаты, курсы, награды, интересы) → подпись, из какого PDF заполнено.
2. **Личные**: Основное (имя, отчество, фамилия, как обращаться, возраст) → Контакты (email, телефон, почта для входа — не редактируется) → Условия работы (чипсы занятости/формата) → Ещё о себе (ссылки, переезд, водительские права, ограничения по трудоустройству — строки с кнопкой «+»).
3. **Файлы**: карточка «Сейф резюме» с иллюстрацией → кнопка «Загрузить PDF» → «Сейчас в профиле» (активное резюме, выделено) → «Другие версии» (Сделать активным / посмотреть / удалить).
4. **Отзывы**: пустое состояние — иллюстрация, «Рейтинг ещё не считается», прогресс «0 из 3 смен».
