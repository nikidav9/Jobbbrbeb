# Job Tools — Настройки, Помощь, Пригласить друга, Молния

7 экранов в едином стиле приложения. Верстать 1:1 по HTML (открываются в браузере без интернета, ссылки между экранами работают).
Ширина **390 pt**, высота 844 (iPhone 14/15). 1 px = 1 pt = 1 dp.

**Все стили вынесены в `assets/jt.css`** — там переменные цветов и готовые классы компонентов (кнопки, поля, шторка, модалка, пузыри чата, аккордеон). По нему удобно собрать компоненты в приложении.

## Экраны и поведение

**Молния (01).** Модальное окно по центру поверх затемнённой ленты (`rgba(20,20,20,.5)`): белое, контур 2, тень `6px 6px 0 #141414`, скругление 28. Иконка молнии в круге 76 (`#FFE2CC`, контур 2). Две плашки: сколько осталось сегодня и когда обновится (00:00). Кнопки «Посмотреть свои отклики» → раздел «Отклики», «Закрыть». Закрывается и тапом по затемнению.

**Пригласить друга (02).** Карточка-«наклейка» с текстом, код в пунктирной плашке `#FFE2CC` (Unbounded 24, разрядка .12em) с кнопкой «копировать», главная кнопка «Поделиться ссылкой» (системное меню «Поделиться»), вторичная «Скопировать ссылку» (после копирования — тост «Ссылка скопирована»). Ниже статистика «позвали / вышли на смену» и пояснение. Код на макете — пример.

**Настройки (03).** Разделы «Аккаунт» и «JobToo» — белые карточки-списки: строка 64, иконка в плитке 40×40 `#FFE2CC`, стрелка ›. У «Уведомлений» справа статус «Вкл/Выкл». Внизу «Выйти из аккаунта» (контур и текст `#C2410C`) → подтверждение.

**Сменить пароль (04).** Нижняя шторка поверх настроек. 3 поля с «глазом» (показать/скрыть). Поле в фокусе — контур 2 + оранжевая тень. «Сохранить» неактивна, пока все поля не заполнены и новые пароли не совпадают; ошибки — под полем, `#C2410C`, 13 / 700. Ссылка «Нет пароля? Задайте его по коду из письма» → экран ввода кода.

**Уведомления (05).** Шторка со статусом: включены (чёрный круг с оранжевой галкой) / выключены (белый круг с пунктиром, кнопка «Включить уведомления» становится главной оранжевой).

**Помощь (06).** Чат. Пузыри: мои — оранжевые с контуром 2 справа; бот JobToo — `#FFE2CC` слева; оператор — белые слева. Над пузырём слева — подпись отправителя 12 / 800. Кнопка «Позвать оператора» (контур 2) после ответов бота. Поле ввода закреплено внизу; кнопка отправки 52×52 неактивна (`#E8DED1`), пока поле пустое, при вводе — оранжевая с контуром 2.

**Частые вопросы (07).** Шторка почти на весь экран (фон `#F5EFE6`), аккордеон: вопрос 16 / 800, стрелка ˅. Открытый вопрос — контур 2 + тень-наклейка, ответ 14 / 600 `#4A443D`. Одновременно открыт один вопрос. Ответы на остальные вопросы — из текущего приложения.

## Общие правила
- Шапка: круглая кнопка «назад» 44×44, контур 2; заголовок Unbounded 700, 18–20.
- Шторки: белые (FAQ — кремовые), скругление 28 сверху, контур 2 по верхнему краю, «ручка» 44×5, крестик 40×40. Закрываются свайпом вниз, крестиком или тапом по затемнению.
- Главная кнопка: высота 58, `#FF6B1A`, контур 2, тень `4px 4px 0 #141414`, скругление 29. Вторичная — белая с контуром 2. Третичная («Закрыть», «Отмена») — просто текст `#6B645C`.

## Цвета

| Токен | HEX | Где используется |
|---|---|---|
| `accent` | `#FF6B1A` | Главная кнопка, «лайк», активные фильтры, активная вкладка, точки-индикаторы |
| `ink` | `#141414` | Основной текст, контуры, тени-«наклейки», нижнее меню, кнопка фильтров |
| `background` | `#F5EFE6` | Фон экранов, плашки в карточке |
| `surface` | `#FFFFFF` | Карточки, поле поиска, круглые кнопки |
| `accent-soft` | `#FFE2CC` | Круг под иллюстрацией, плашка «з/п не указана» |
| `stack-1` / `stack-2` | `#F1E9DE` / `#E8DED1` | Карточки в стопке под текущей |
| `border-soft` | `#CFC4B6` | Контур неактивных фильтров и «Подробнее» |
| `muted` | `#D9CFC2` | Неактивные точки-индикаторы |
| `text-secondary` | `#5C554D` | Подзаголовок на стартовом экране |
| `text-tertiary` | `#6B645C` | Мелкий текст, «Карьерный сайт · 2 дня назад», счётчик вакансий |
| `text-body` | `#4A443D` | Описание вакансии |

Текст на оранжевом — **чёрный** `#141414` (белый на этом оранжевом плохо читается).

## Шрифты

- **Unbounded 700** — крупные заголовки: стартовый экран 31/35, название вакансии 21/25, letter-spacing −0.01em.
- **Manrope** — всё остальное:
  - кнопки 18 / 700;
  - фильтры и «Подробнее» 14 / 700;
  - описание вакансии 15 / 500, межстрочный 1.5;
  - подзаголовок онбординга 16 / 500, межстрочный 1.45;
  - мелкий текст 12–13 / 600.
