# Job Tools (JT) — экран «Отклик» (статус отклика)

Экран открывается по тапу на отклик в разделе «Отклики». Здесь 3 состояния одного экрана.
Верстать 1:1 по HTML (открываются в браузере без интернета). Ширина **390 pt**, экран прокручивается; 1 px = 1 pt = 1 dp.

## Что в архиве

| Файл | Состояние |
|---|---|
| `01-needs-you.html` | **Нужны вы** — отклик сохранён, но пользователь должен сам отправить анкету (сайт работодателя ещё не подключён) |
| `02-sent.html` | **Отправлено** — Юпитер отправил отклик, ждём ответа работодателя |
| `03-closed.html` | **Вакансия закрыта** — работодатель закрыл вакансию, отклик не отправлен |
| `screenshots/*.png` | скриншоты @3x для сверки |
| `assets/icons/*.svg` | иконки экрана, 24×24 (цвет в SVG — чёрный, перекрашивать по макету) |
| `assets/fonts/` | Unbounded и Manrope (woff2) + `fonts.css`, лицензия OFL |

## Структура экрана (одинакова для всех состояний)

1. **Шапка:** кнопка «назад» 44×44 (круг, контур 2) слева, заголовок «Отклик» по центру — Unbounded 700, 18.
2. **Карточка вакансии** (белая, скругление 24, отступы 24/18, всё по центру):
   - логотип компании 64×64, скругление 18 (на макете — буква; в приложении подставлять настоящий логотип);
   - название вакансии — Unbounded 700, 20, межстрочный 1.25;
   - компания — Manrope 15 / 700, `#6B645C`;
   - ссылка на сайт вакансии — 14 / 800 с оранжевым подчёркиванием 2 px и стрелкой ↗ (открывает браузер);
   - бейдж статуса (высота 32, скругление 16, 13 / 800) — см. таблицу ниже;
   - кнопка действия, если оно есть.
3. **Плашка про согласия** (белая, скругление 18): иконка щита, текст 13 / 600 `#4A443D`, ссылка «Условия и политика работодателя ↗».
4. **«История отклика»** — заголовок Unbounded 700, 15, под ним белая карточка (скругление 22) с таймлайном: **новые события сверху**.

## Таймлайн — типы шагов

Иконка-кружок 40×40 слева, между кружками вертикальная линия 2 px `#E3D9CC`. Справа: заголовок 16 / 800, пояснение 14 / 600 `#4A443D` (если есть), время 13 / 600 `#6B645C` в формате «27 сент., 12:01».

| Шаг | Кружок |
|---|---|
| Текущее действие от пользователя («Нужны вы», если оно сейчас активно) | оранжевый `#FF6B1A`, контур 2 чёрный, тень `3px 3px 0 #141414`, иконка «рука» |
| «Нужны вы» в прошлом (уже выполнено) | белый, контур 2 чёрный, иконка «рука» |
| В очереди Юпитера | `#FFE2CC`, иконка «часы» |
| Выполнено (Вы откликнулись, Вы дали согласие) | чёрный `#141414`, оранжевая галка |
| Юпитер отправил отклик | чёрный `#141414`, оранжевый «самолётик» |
| Ожидание (Ждём ответа работодателя) | белый, пунктир 2 `#9A9086`, три точки; заголовок `#4A443D`, без времени |
| Закрыто (Работодатель закрыл вакансию) | белый, пунктир 2 `#9A9086`, серый замок; заголовок `#4A443D`, без времени |

## Логика
- Бейдж и кнопка в карточке берутся из **последнего** шага истории.
- «Нужны вы» может появляться несколько раз (например, работодатель просит согласие) — каждый раз новым шагом сверху.
- Когда работодатель ответит, сверху появится шаг с ответом (приглашение / отказ) — макет этого шага сделаем отдельно.

## Цвета

| Токен | HEX | Где используется |
|---|---|---|
| `accent` | `#FF6B1A` | Главная кнопка, «лайк», активные фильтры, активная вкладка, точки-индикаторы |
| `ink` | `#141414` | Основной текст, контуры, тени-«наклейки», нижнее меню, кнопка фильтров |
| `background` | `#F5EFE6` | Фон экранов, плашки в карточке |
| `surface` | `#FFFFFF` | Карточки, поле поиска, круглые кнопки |
| `accent-soft` | `#FFE2CC` | Круг под иллюстрацией, плашка «з/п не указана» |
| `stack-1` / `stack-2` | `#F1E9DE` / `#E8DED1` | Карточки в стопке под текущей |
| `border-soft` | `#CFC4B6` | Контур неактивных фильтров и «Подробнее» |
| `muted` | `#D9CFC2` | Неактивные точки-индикаторы |
| `text-secondary` | `#5C554D` | Подзаголовок на стартовом экране |
| `text-tertiary` | `#6B645C` | Мелкий текст, «Карьерный сайт · 2 дня назад», счётчик вакансий |
| `text-body` | `#4A443D` | Описание вакансии |

Текст на оранжевом — **чёрный** `#141414` (белый на этом оранжевом плохо читается).

## Шрифты

- **Unbounded 700** — крупные заголовки: стартовый экран 31/35, название вакансии 21/25, letter-spacing −0.01em.
- **Manrope** — всё остальное:
  - кнопки 18 / 700;
  - фильтры и «Подробнее» 14 / 700;
  - описание вакансии 15 / 500, межстрочный 1.5;
  - подзаголовок онбординга 16 / 500, межстрочный 1.45;
  - мелкий текст 12–13 / 600.
