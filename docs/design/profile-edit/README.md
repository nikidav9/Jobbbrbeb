# Job2 — Профиль: экраны редактирования

20 экранов, которые открываются по карандашу ✎ и по оранжевому «+» в профиле.
Верстать 1:1 по HTML-файлам (открываются в браузере без интернета). Макеты под ширину **390 pt** (iPhone 14/15), 1 px = 1 pt = 1 dp.

## Общие правила экранов

- **Шапка:** круглая кнопка «назад» 44×44 (контур 2) + заголовок Unbounded 700, 18–20. Справа — «Удалить» (красно-оранжевый `#C2410C`, подчёркнут) только у уже существующих записей.
- **Кнопка внизу** закреплена: высота 60, `#FF6B1A`, контур 2, тень `4px 4px 0 #141414`, скругление 30. Текст: «Сохранить» — при редактировании, «Добавить» — при создании новой записи (экраны с «+»). Над кнопкой растворение фона, если экран прокручивается.
- **Пока ничего не изменено** или не заполнено обязательное — кнопка неактивна: фон `#E8DED1`, текст `#9A9086`, без контура и тени.
- **Выход без сохранения** с изменениями → спросить «Сохранить изменения?» (Сохранить / Не сохранять).
- **После сохранения** — возврат в профиль и короткое уведомление «Сохранено».
- **Нижняя шторка** (email, телефон): затемнение `rgba(20,20,20,.5)`, белая шторка со скруглением 28 сверху, контур 2 по верхнему краю, «ручка» 44×5, крестик 40×40. Закрывается свайпом вниз или тапом по затемнению.

## Что на макетах — пример
Данные в полях взяты из текущего профиля или показаны плейсхолдерами. Email и телефон на макетах заменены на обезличенные (`name@mail.ru`, `+7 999 000-00-00`). Выбранные чипы (формат, интересы, категории прав, города переезда и т.д.) — пример состояния.

Текст на оранжевом — **чёрный** `#141414` (белый на этом оранжевом плохо читается).

## Шрифты

- **Unbounded 700** — крупные заголовки: стартовый экран 31/35, название вакансии 21/25, letter-spacing −0.01em.
- **Manrope** — всё остальное:
  - кнопки 18 / 700;
  - фильтры и «Подробнее» 14 / 700;
  - описание вакансии 15 / 500, межстрочный 1.5;
  - подзаголовок онбординга 16 / 500, межстрочный 1.45;
  - мелкий текст 12–13 / 600.
