# Job Tools — загрузочный экран (splash): раскадровка

6 кадров анимации + живой превью. Верстать 1:1; экран 390×844 pt (iPhone 14/15), 1 px = 1 pt = 1 dp.

## Композиция
- Фон `#F5EFE6` на весь экран (и в системном launch screen iOS/Android — тот же цвет, чтобы не было «вспышки»).
- Плашка 140×140, центр в точке (195, 380): белая, контур 2 `#141414`, скругление 36, внутри логотип шириной 96.
- Подпись «Работа в IT — свайпом» — Unbounded 700, 18, верх на 486.
- Прогресс-бар 180×14: белый, контур 2, скругление 7, заливка `#FF6B1A` с чёрной правой гранью 2 px. Под ним «Подбираем вакансии…» — Manrope 13 / 700, `#6B645C`.

## Раскадровка и тайминги (цикл 0–2,8 с)

| Кадр | Время | Что происходит | Кривая |
|---|---|---|---|
| 1 · Точка | 0 → 300 мс | В центре появляется оранжевая точка 18×18 (scale 0 → 1) | ease-out |
| 2 · Плашка | 300 → 600 мс | Точка раскрывается в плашку 140×140: scale 0.13 → 1, скругление 70 → 36, цвет оранжевый → белый | cubic-bezier(.2,.8,.2,1) |
| 3 · Логотип | 600 → 1000 мс | Логотип «впрыгивает»: scale 0.6 → 1.08 → 1, прозрачность 0 → 1 | cubic-bezier(.3,1.4,.5,1) — с отскоком |
| 4 · Наклейка | 900 → 1300 мс | Появляется тень-наклейка 0 → `6px 6px 0 #141414`; подпись всплывает (translateY 10 → 0, opacity 0 → 1) | ease-out |
| 5 · Загрузка | 1300 → 2400 мс | Прогресс-бар заполняется. **Реальный прогресс = загрузка данных ленты**; если всё готово раньше — бар быстро добегает до 100% за 200 мс | cubic-bezier(.4,0,.2,1) |
| 6 · Переход | 2400 → 2900 мс | Подпись и бар гаснут; плашка уменьшается (scale 1 → 0.33) и улетает в левый верх — на место логотипа в шапке ленты, по пути растворяясь; скелетон ленты проявляется снизу (translateY 12 → 0), затем подгружаются настоящие карточки | cubic-bezier(.2,.8,.2,1) |

Минимальное время показа — 1,3 с (до конца кадра 4), даже если данные уже загружены: так анимация не обрывается. Максимум — пока не загрузится лента; если дольше 8 с — под баром текст «Долго грузится… Проверьте интернет» и кнопка «Повторить».

Повтор в `07-animated-preview.html` — только для просмотра; в приложении анимация проигрывается один раз.

## Доступность
При включённом «Уменьшении движения» (Reduce Motion) — без анимации: сразу кадр 5 (плашка с тенью, подпись, бар), затем плавная смена на ленту (fade 200 мс).

## Реализация
- iOS: системный Launch Screen = только фон `#F5EFE6` (без логотипа), дальше — этот экран в приложении.
- Android 12+: SplashScreen API с фоном `#F5EFE6` и иконкой-точкой, затем этот экран.
- Удобно собрать в Lottie / Rive по кадрам выше или напрямую анимациями платформы.
