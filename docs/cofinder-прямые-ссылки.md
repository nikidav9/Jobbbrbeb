# Как Cofinder делает ссылки на вакансии

Владелец спросил: «зайти на конкурента и понять, какие ссылки он вставляет,
как он это делает». Разобрано 16.09.2026 по их публичному API, без логина,
без обхода ограничений. Инструмент — `scripts/cofinder-link-hints.mjs`.

## Короткий ответ

**Только карьерный сайт работодателя. Ни одной ссылки на агрегатор.**

Проверено 191 пример ссылки у 97 компаний: 191 из 191 ведёт на собственный
домен работодателя (`career.rwb.ru/vacancies/39721`, `job.mts.ru/vacancy/…`,
`rabota.sber.ru/search/vacancy-4570723/`). На hh.ru, SuperJob, Avito, Хабр
Карьеру — ноль. Решение владельца «переводить только на карьерный сайт»
совпадает с тем, как это устроено у конкурента.

Механика простая и нам уже доступна: у них реестр компаний с полем
`career_url` и статусом разбора, а у каждой вакансии — прямой URL вида
`<карьерный домен>/vacanc(y|ies)/<id>`. Это ровно тот шаблон `html_links`,
который наш коннектор умеет читать. Ничего закрытого, никакого JS-рендера
на выдаче ссылок.

## Чего я не угадал

Я предполагал, что дело в географии: мол, они ходят с российских адресов,
поэтому им отвечают, а нам нет. **Гипотеза не подтвердилась, и это надо
сказать прямо.** У них в каталоге 14 компаний со статусом `error`, и ошибки
те же, что у нас:

| Компания | Что у них в сообщении |
|---|---|
| Альфа-Банк | падение Selenium со стектрейсом |
| Точка Банк, Positive Technologies, НСПК | `[SSL: CERTIFICATE_VERIFY_FAILED]` |
| СИБУР, Cloud.ru, Arenadata, Юзтех, Индасофт, Спортс, Лоция, Гараж 8, Effective Technologies | `Parser returned 0 vacancies` |
| Контакт | `'NoneType' object has no attribute 'lower'` |

Их 829 вакансий Альфа-Банка — снимок от 29.07.2026, `days_since_update: 49`,
без описаний. Живого доступа к Альфа-Банку у них нет, есть старый слепок.

Зато по десяти крупнейшим (Сбер, МТС, ВТБ, Ozon, Яндекс, Т-Банк, Avito,
Ростелеком, Wildberries, Lamoda) `found_at` — сегодняшний, `days_since_update: 0`.
Значит, эти сайты **не закрыты ни для кого**, и наши нули по ним — не стена,
а наш разбор.

## Разрыв, который из этого виден

98 компаний из нашего списка Cofinder разбирает, а у нас на проде по ним ноль
вакансий. Суммарно **11 765 вакансий**. Полная таблица со статусами, ошибками
и примером прямой ссылки по каждой компании — `docs/данные/cofinder-разрыв.tsv`.

Первая десятка по объёму: Сбер 1841, МТС 1571, Росатом 1129, Яндекс 1097,
Ozon 892, ВТБ 740, Т-Банк 543, VK 264, Золотое Яблоко 239, Ростелеком 224.

Cofinder в продакшен-фид не подключается и тексты вакансий оттуда не берутся —
это только подсказка, по какому шаблону строится ссылка на карьерном сайте.

После миграции `089_consolidate_career_catalog` legacy-источник `career`
выключен, всё живёт под `career_owner`.

| Отпечатков против строк | 1343 при 1583 строках (теряли 240) | 695 при 695 строках (теряем 0) |
| METRO | 294 строки, 100 отпечатков | 299 строк, 299 отпечатков |
| С описанием | 858 из 1583 (54%) | 679 из 695 (98%) |

Обе правки сработали. Но общее число упало с 1583 до 695 по 18 компаниям:

задача, не следствие починки отпечатков.
